# Moved to OneSolar

Orders, Sponsors and Finances now live in **[Solar-Gators/one.solar](https://github.com/Solar-Gators/one.solar)**
(`orders/`), together with every other OneSolar app, at **https://solar-gators.github.io/one.solar/orders/**.

This repo only keeps the old address working: `index.html` sends every old link and bookmark
(including `#/requests/…` and sign-in links) to the new address, and `sw.js` clears the old installed app.
The full history is in the one.solar repo too.
